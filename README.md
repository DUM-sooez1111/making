# BLOCK FIELD

128 × 128 베이스플레이트에서 블록을 설치하는 웹 3D 게임입니다.

## 로컬 실행

Node.js가 설치된 환경에서 이 폴더의 터미널로 `node serve.mjs`를 실행한 뒤 http://127.0.0.1:4173 에 접속하세요. HTML 파일을 직접 여는 대신 서버로 실행해야 합니다.

## 조작

- 화면 클릭: 마우스를 중앙에 고정하고 시점 이동 시작 / Esc: 마우스 해제
- Tab: 블록 메뉴를 열면 마우스 고정 해제, 닫으면 다시 고정 / 1–8: 블록 선택
- WASD: 이동 / Space: 상승 / Q: 하강 / Shift: 빠른 이동
- 좌클릭: 설치 / 우클릭: 삭제
- 터치 화면: 드래그로 시점 이동, 화면 버튼으로 이동·설치·삭제

자유 비행 건축 모드이며, 베이스플레이트는 삭제되지 않습니다. 설치 범위는 바닥 128 × 128, 높이 64칸, 최대 5,000개입니다. 현재 버전은 새로고침하면 건축물이 초기화됩니다.

Three.js 0.170.0을 로컬로 포함했습니다. 라이선스: dist/vendor/THREE-LICENSE.txt.
